3. API ENDPOINTS
================================================================================

Location: src/app/api/features.ts
Type: TypeScript API Route Handlers

ENDPOINTS:
├─ GET /api/features
│  └─ List all features with status for business
│
├─ GET /api/features/:feature_name
│  └─ Check single feature availability
│
├─ POST /api/admin/features/:feature_name/enable
│  └─ Enable feature (admin only)
│
├─ POST /api/admin/features/:feature_name/disable
│  └─ Disable feature (admin only)
│
├─ POST /api/admin/features/:feature_name/rollout
│  └─ Update rollout percentage (0-100%)
│
└─ GET /api/admin/features/usage
   └─ Feature analytics for past 30 days

RESPONSE CODES:
├─ 200: Success
├─ 400: Bad request (missing parameters)
├─ 402: Payment Required (feature not available)
├─ 403: Forbidden (not admin)
├─ 404: Feature not found
├─ 405: Method not allowed
└─ 500: Server error

Type: TypeScript Middleware

FUNCTIONS:

│

   └─ Rate limiting (default 100 req/min)

SECURITY:

├─ Admin-only protection
├─ Rate limiting
├─ Audit logging
└─ Graceful error handling
