### Red Flags & Alerts

**Stop if:**
- MRR growth < 15% for 2 consecutive months (below trendline)
- Churn > 3.5% (rising unexpectedly)
- CAC > $700 (inefficient acquisition)
- ARPU declining month-over-month (product issues)
- NPS < 40 (product satisfaction)
- Burn rate accelerating > 10% per month
- Team headcount dropping unexpectedly

**Action if red flags appear:**
1. Diagnosis (product, market, competition, execution)
2. Root cause analysis (why is metric declining?)
3. Action plan (immediate 30-day fixes)
4. Investor communication (transparency)
