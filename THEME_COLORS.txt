╔══════════════════════════════════════════════════════════════════════════════╗
║                    THEME SWITCHING                                          ║
╚══════════════════════════════════════════════════════════════════════════════╝

✅ Light Theme (Default)
   - Clean, professional iOS-style appearance
   - Perfect for daytime use
   - White cards with navy and orange accents
   - Dark text on light backgrounds

✅ Dark Theme (Toggle)
   - Navy background for reduced eye strain
   - Perfect for evening use
   - Dark navy cards with vibrant orange CTAs
   - Light text on dark backgrounds
   - Orange borders instead of gray

✨ Both themes share:
   - Same brand colors (Orange, Navy, Light Blue)
   - Perfect accessibility (WCAG AA/AAA)
   - Automatic switching via CSS variables
   - Consistent user experience

╔══════════════════════════════════════════════════════════════════════════════╗
║                    USAGE IN CODE                                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

CSS Variables:
  var(--primary)              /* #FF9E1B */
  var(--secondary)            /* #1a3a52 */
  var(--accent)               /* #87CEEB */
  var(--background)           /* #f8f9fa or #0f1d2d */
  var(--foreground)           /* #1a1a1a or #f0f0f0 */

Tailwind Classes:
  bg-primary                  <!-- Orange background -->
  bg-secondary                <!-- Navy background -->
  bg-accent                   <!-- Light blue background -->
  text-foreground             <!-- Automatic text color -->
  text-muted-foreground       <!-- Secondary text color -->
  border-primary              <!-- Orange border -->
  hover:bg-primary/90         <!-- Orange with hover state -->

║                    ACCESSIBILITY COMPLIANCE                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

Orange (#FF9E1B) on White (#ffffff):        4.8:1 - WCAG AA ✅
Navy (#1a3a52) on White (#ffffff):          8.1:1 - WCAG AAA ✅
Navy (#1a3a52) on Light Gray (#f8f9fa):    7.2:1 - WCAG AAA ✅
Orange (#FF9E1B) on Dark Navy (#0f1d2d):   5.2:1 - WCAG AA ✅
Light Blue (#87CEEB) on Navy (#1a3a52):    4.1:1 - WCAG AA ✅
Light Gray (#f0f0f0) on Dark Navy (#0f1d2d): 6.5:1 - WCAG AA ✅

All color combinations meet WCAG AA or higher standards ✨
